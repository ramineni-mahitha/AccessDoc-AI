# ♿ AccessDoc AI – AI-Powered Accessibility Converter

**Making public documents easier to understand, access, and use.**

AccessDoc AI is an AI-powered web application designed to improve the accessibility of public documents, notices, and institutional information. It helps users convert complex PDF documents into simpler, more understandable and accessible formats.

## 🚀 Features

- 📄 **PDF Processing:** Upload and extract text from PDF documents.
- 🧠 **AI Text Simplification:** Convert complex sentences into easy-to-understand language.
- 🌐 **Multilingual Translation:** Translate extracted content into multiple languages, including Telugu, Hindi, Tamil, and Kannada.
- 🔊 **Text-to-Speech:** Convert document text into audio for easier listening.
- 📥 **Download Support:** Download processed content for future reference.
- 🤖 **AI Agent Workflow:** Uses AI-powered processing steps to improve document accessibility.

## 🛠️ Technologies Used

- Python
- Streamlit
- Google Gemini API
- PDF Processing Libraries
- Text-to-Speech
- AI Agent Workflow

## ⚙️ How to Run Locally

1. Clone this repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Navigate to the project folder:

   ```bash
   cd AccessDoc-AI
   ```

3. Install the required dependencies:

   ```bash
   pip install -r requirements.txt
   ```

4. Configure your API key securely using Streamlit secrets.

5. Run the application:

   ```bash
   streamlit run app.py
   ```

6. Open the local URL displayed in your terminal.

## 🎯 Project Objective

The main objective of AccessDoc AI is to make public and institutional information more inclusive by reducing language barriers and simplifying complex documents.

It aims to support students, citizens, and individuals who need accessible ways to understand important information.
